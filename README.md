# TP 3 — Gestion des produits

## Environnement
- JDK 17
- Maven
- Spring Boot 3.5.16
- H2 en mémoire

## Lancer dans VS Code
1. Ouvrir le dossier `product-mvc`.
2. Vérifier que Java 17 et Maven sont disponibles.
3. Dans le terminal intégré, exécuter `mvn spring-boot:run`.
4. Ouvrir http://localhost:8080

## Comptes de test
- USER : `user1` / `1234`
- ADMIN : `admin` / `1234`

La base H2 est en mémoire : les données sont réinitialisées à chaque redémarrage.
